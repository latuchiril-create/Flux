Этот файл содержит описание аватара по умолчанию для водяного знака.

Аватар по умолчанию должен быть:
- Размер: 24x24 пикселя
- Формат: PNG
- Содержание: Простая иконка пользователя или кота (как показано на изображении)
- Цвета: Темные тона для лучшей видимости на светлом фоне

Для создания аватара:
1. Создайте изображение 24x24 пикселя
2. Сохраните как PNG
3. Замените этот .txt файл на .png файл
4. Убедитесь, что файл называется "default_avatar.png"

Альтернативно, можно использовать существующий файл circle.png, переименовав его в default_avatar.png.
