Создай статичный UI-макет окна настроек «Автобай» для игрового клиента.

ВАЖНО: это именно дизайн интерфейса, не код. Покажи одно цельное окно приложения на тёмном фоне.

ОСНОВНАЯ ИДЕЯ
Автобай сейчас настраивается для МЕЧЕЙ, но в интерфейсе должен остаться компактный выбор категории предмета.
Категория по умолчанию: «Мечи».

Не делай отдельные вкладки:
— Основные
— Фильтры
— Параметры
— Дополнительно

Никакого левого sidebar.
Все настройки находятся в одном цельном окне и читаются сверху вниз.

СТИЛЬ
Ориентируйся на приложенные референсы по цветовой гамме:
— почти чёрный холодный фон;
— немного более светлая поверхность окна;
— тонкие серо-синие borders;
— основной текст светло-серый;
— вторичный текст приглушённый серо-синий;
— фиолетовый используется ТОЛЬКО для активных элементов;
— белые/светлые бегунки переключателей;
— никаких кислотных цветов.

Примерная палитра:
background: #0c0e14
surface: #11141c
surface secondary: #151924
border: #252b3a
primary text: #d9dde8
secondary text: #8991a5
accent: #7c3aed / #8b5cf6

НЕ ДЕЛАЙ:
— glassmorphism;
— огромные glow-эффекты;
— неоновую рамку вокруг всего интерфейса;
— градиент на каждом элементе;
— иконку около каждой строки;
— декоративные карточки ради карточек;
— огромные заголовки;
— игровые мечи/сундуки как декоративные арты;
— fake 3D;
— floating elements;
— «AI dashboard» стиль;
— случайные графики;
— статистику;
— rarity / редкость меча;
— кнопки «обычный / редкий / эпический / легендарный»;
— разделение интерфейса на страницы или категории настроек;
— слишком большие отступы.

Интерфейс должен выглядеть как реально спроектированная панель игрового клиента:
плотный, спокойный, аккуратный, функциональный desktop UI.

КОМПОЗИЦИЯ

Верхняя строка:
«Автобай»
небольшой приглушённый текст рядом или снизу: «Автоматическая покупка предметов»

Справа небольшой аккуратный переключатель:
«Автобай включён»

Ниже первая строка:

Категория
[ Мечи                         ▾ ]

Это обычный качественный select/dropdown.
Он не должен занимать половину экрана.

Дальше настройки без отдельных огромных контейнеров.

1. Фильтр цены

Слева:
«Максимальная цена»

Справа аккуратное числовое поле:
[ 3 000 000 ]

Рядом или внутри поля можно использовать небольшой muted suffix/indicator валюты, если это выглядит естественно.

2. Прочность

Строка:
«Учитывать прочность»       [ toggle ]

Когда включено, ниже появляется:

«Минимальная прочность»

тонкий slider -------------------------------- [ 10% ]

Slider должен выглядеть современно:
узкий track, фиолетовая заполненная часть, небольшой круглый thumb.
Без огромного свечения.

3. Чары

«Обязательные чары»

Большой аккуратный multi-select:
[ Острота V × ] [ Вампиризм II × ]     Добавить чары...

Следующая строка:

«Игнорируемые чары»

[ Нестабильный × ] [ Проклятие × ]     Добавить чары...

Теги компактные.
Не превращай их в яркие фиолетовые капсулы.
Лучше тёмные chip-компоненты с тонкой фиолетовой active border.

4. Автоперепродажа

«Авто-перепродажа»         [ toggle ]

Под названием маленьким приглушённым текстом:
«Перепродавать подходящие купленные предметы»

Если включено, рядом или ниже:

«Минимальная прибыль»

slider ------------------------------ [ 15% ]

5. Анти-слив баланса

«Анти-слив баланса»        [ toggle ]

Небольшое описание:
«Останавливать покупки при достижении лимита»

При включении:
«Минимальный остаток»
[ 500 000 ]

6. Анархия

«Свитч по анархиям»        [ toggle ]

Ниже компактный multi-select:
[ 231 × ] [ 232 × ] [ 234 × ] [ 233 × ]

Не делай эти элементы огромными.

7. Дополнительные настройки обычными строками:

«Реклама на анархии»       [ toggle ]

«Аренда слотов»            [ toggle ]

8. Запрещённые продавцы

Поле:
«Запрещённые продавцы»

[ player123 × ] [ badseller × ]       Добавить ник...

НИКАКИХ НАСТРОЕК БАФФОВ.
Не добавлять:
— нужные баффы;
— игнорируемые баффы;
— только взрывные баффы.

НИКАКОЙ РЕДКОСТИ ПРЕДМЕТОВ.

НИЖНЯЯ ЧАСТЬ

Тонкий separator.

Слева текстовая secondary-кнопка:
«Сбросить»

Справа:
secondary button «Отмена»
primary button «Сохранить»

Primary button не должен быть огромной glowing-плашкой.
Обычная качественная кнопка высотой примерно 40–44 px,
фиолетовый фон,
небольшой hover-like highlight,
радиус примерно 8–10 px.

ВИЗУАЛЬНАЯ СИСТЕМА

Используй:
— радиус полей 7–10 px;
— радиус основного окна около 12–14 px;
— высота input 38–42 px;
— одинаковую сетку;
— выравнивание подписей;
— визуальную иерархию через spacing, font weight и тонкие separators;
— максимум 1–2 декоративных акцента на всём экране.

Иконки использовать только там, где они действительно нужны:
например маленькая стрелка dropdown и крестик удаления chip.
Не ставить иконки возле «Цена», «Прочность», «Автоперепродажа» и каждой другой настройки.

Шрифт:
современный нейтральный sans-serif в духе Inter / Geist / SF Pro.
Без футуристического sci-fi шрифта.

Главная цель:
интерфейс должен выглядеть как работа сильного UI/UX-дизайнера игрового клиента, а не как автоматически сгенерированный SaaS dashboard.

Сделай дизайн аккуратным, компактным и правдоподобным.
Фокус на хорошей типографике, spacing, формах контролов и состоянии элементов.
